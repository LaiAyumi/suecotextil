# SUECO Têxtil — Site institucional

Site institucional e catálogo digital para a SUECO Têxtil, com apresentação de coleções, cartela de cores, cartela de estampas e catálogo de produtos.

## ✨ Funcionalidades

- Catálogo de produtos com modais de detalhe por item
- Cartela de cores e cartela de estampas interativas
- Página de coleções (incluindo coleção destacada "Aura")
- Estampas personalizadas
- Layout totalmente responsivo, múltiplas páginas navegáveis

## 🚀 Como rodar

Não depende de build — basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```
